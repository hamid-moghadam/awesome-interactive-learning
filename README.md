## Networking & Internet

- [How DNS Works](https://howdns.works/) – Beautiful interactive explanation of DNS
- [How HTTPS Works](https://howhttps.works/) – Interactive HTTPS deep dive
- [How DNSSEC Works](https://howdnssec.works/) – Interactive DNSSEC explanation
- [200ms – The Node Book](https://200ms.thenodebook.com/) – Interactive networking concepts

## Operating Systems & Systems

- [Writing an OS in Rust](https://os.phil-opp.com) – Excellent series that builds a real OS
- [The Deadlock Empire](https://deadlockempire.github.io/) – Interactive concurrency & deadlock puzzles
- [PGSimCity](https://nikolays.github.io/PGSimCity/) – Process scheduling simulator

## Git & Version Control

- [Learn Git Branching](https://learngitbranching.js.org/) – The classic interactive Git tutorial
- [Oh My Git!](https://ohmygit.org/) – Beautiful visual Git learning game
- [Git by Bit](https://gitbybit.com/) – Interactive Git lessons

## Containers & Docker

- [Play with Docker Training](https://training.play-with-docker.com/) – Official interactive Docker labs
- [iximiuz Labs](https://labs.iximiuz.com/) – Excellent container & Kubernetes playgrounds

## Mathematics & Visualizations

- [Math is Fun](https://www.mathsisfun.com/) – Clear interactive math explanations
- [Seeing Theory](https://seeing-theory.brown.edu/) – Visual introduction to probability and statistics
- [Immersive Math](https://immersivemath.com/) – Interactive linear algebra
- [AlgoViz](https://www.algoviz.xyz/) – Algorithm visualizations

## Web Development

- [Frontend Mentor](https://www.frontendmentor.io/) – Real-world frontend challenges
- [CSS Grid Garden](https://cssgridgarden.com/) – Learn CSS Grid by growing a garden
- [CryptoZombies](https://cryptozombies.io/) – Learn Solidity + frontend by building a game

## Security, CTF & Cryptography

- [OverTheWire Wargames](https://overthewire.org/wargames/) – Classic progressive security challenges
- [pwn.college](https://pwn.college/) – University-style interactive security education
- [CryptoHack](https://cryptohack.org/) – Interactive cryptography challenges
- [Click Deeper](https://clickdeeper.com/) – Interactive privacy & tracking exploration

## Command Line & Shell

- [CMD Challenge](https://cmdchallenge.com/) – Practice Linux command line
- [RegexOne](https://regexone.com/) – Interactive regular expressions tutorial

## Other Great Resources

- [Wizard Zines](https://wizardzines.com/) – Excellent illustrated zines (many interactive concepts)
